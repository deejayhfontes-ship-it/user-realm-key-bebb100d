# VISUAL-PROMPTS — BEM Topografia e Engenharia

Prompts completos para gerar manualmente todos os assets do site. Cada prompt é autônomo:
copie o bloco inteiro e cole no gerador. Nenhum prompt depende de outro para ser entendido;
o que precisa ser preservado está repetido dentro de cada um (bloco CONTINUITY LOCK).

Idioma dos prompts: inglês (melhor resposta dos geradores). Notas de produção em português.

**Regras gerais de produção**

- Gerar primeiro a **01 — MASTER REFERENCE IMAGE** e usá-la como referência de imagem
  (image reference / style reference / IP-adapter, conforme o gerador) em todas as outras.
- Frames `start` e `end` de cada cena são gerados como imagens. Depois, o vídeo é gerado
  a partir do par (first frame → last frame) com o prompt de animação.
- Proporção padrão das cenas: **16:9** (2560×1440 para frames, 1920×1080 para vídeo).
- Duração de cada vídeo: entre 5 e 10 s (indicada por cena).
- Nenhum texto, letra, número, logo ou marca dentro de imagem ou vídeo. Todo texto é HTML.
- Nomes de arquivo estão na letra H de cada cena. Colocar em `assets/cinematic/`.
